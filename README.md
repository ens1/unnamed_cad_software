# TCAD

A local desktop mechanical CAD application built from the specification in `mechanical-cad-build-package`. The desktop, command line, and geometry worker share the same authoritative document and commands. Original application code is WTFPL.

## Product baseline

The product target is the **mainstream mechanical CAD capabilities shared by SolidWorks, NX, Onshape, and Creo**: sketches, solids, surfaces, assemblies, drawings, sheet metal, structural design, tooling, configurations, libraries, inspection, and CAD exchange. The user's latest clarification replaces full SolidWorks parity while retaining equivalent practical modes and parametric behavior. The [mechanical CAD coverage inventory](docs/mechanical-cad-coverage.md) records requirements and current implementation gaps. TCAD has not reached this baseline.

## Start

On this Mac, open **`dist/TCAD.app`** or double-click **`Start TCAD.command`**. The command launcher compiles the workspace before opening it. The app opens an empty **Part1** when no project is supplied. **File → New Part** and **New Assembly** create empty documents. The drive-unit demo is available only through **File → Open Example: Drive Unit**.

From a terminal:

```sh
./scripts/start.sh
./target/debug/tcad-desktop /absolute/path/to/project.json
./target/debug/tcad-desktop --reset-ui
```

The worker executable must sit beside the desktop executable. `TCAD_WORKER` can select another compatible worker. The toolchain is pinned in `rust-toolchain.toml`; the dependency graph is pinned in `Cargo.lock`. Windows and Linux use the same source and native windowing dependencies. The adapter 19 / solver 12 continuation was formatted, compiled, strictly linted and packaged on macOS on 2026-10-11. Other platforms and interactive acceptance remain unverified.

The macOS bundle contains `TCAD` (desktop), `tcad-worker` (geometry), and `tcad-cli` (command line). These names must remain distinct even on case-insensitive filesystems.

## Workflows

- Select **Front Plane**, **Top Plane**, **Right Plane**, or a planar model face, then **Sketch**. Choose lines, corner/center rectangles, circles, 3-point arcs, ellipses, regular polygons, straight slots, control-point splines, or reference points in the Sketch tab and draw directly in the viewport. **Finish** or the orange **Apply** confirms the sketch. In Features, use **Boss / Base**, **Extruded Cut**, or **Revolve**; enter dimensions in Properties and confirm with **Apply**. Confirmation waits for the current valid geometry automatically and creates one undoable change. **Cancel** restores the state before that operation. New geometry starts from sketches; primitive creation commands are absent.
- **Sketch → Edit Entities** includes **Convert Entities**, **Offset Entities**, **Sketch Fillet / Chamfer**, **Trim / Extend / Split**, **Repair Sketch**, **Stretch / Replace Entities**, **Mirror / Pattern / Copy**, **Sketch Text**, **Equation Curve**, and **Construction Geometry**. Convert selected model edges, a face boundary or supported reference-curve pieces with an optional source relation. Offset a connected line/arc chain, a circle, or a spline with a proven exact straight/circular or degree-one polyline carrier. Fillet joined lines or bounded circular arcs with an editable radius. Repair adds explicit coincidence relations for unambiguous endpoint gaps. Text imports a pinned local outline font and creates editable exact sketch contours. Equation Curve creates an exact parametric polynomial with editable coefficients, range, angle and anchor. Inspect the live preview, **Accept** the local operation, then **Apply Sketch** to commit. **Sketch Operations** reopens saved intent or detaches generated geometry. The sketch contextual menu exposes the same actions. Any member type can become construction geometry; it remains available to constraints and handles but does not form solid profiles.
- **Fillet / Chamfer** keeps an edge list: Command/Ctrl/Shift-click several edges before starting, or click edges to add them while the editor is open. Modified clicks toggle, and individual **Remove** / **Clear** controls edit the list. All selected edges stay highlighted. Existing-feature editing picks its cached input body while the preview updates. Native round and bevel geometry, supported corners and remaining limits are documented in [edge fillets](docs/edge-fillets.md) and [edge chamfers](docs/edge-chamfers.md).
- Features are grouped into **Create**, **Remove**, **Modify**, **Pattern**, **Surfaces**, and **Reference**. Extrusion supports Blind, Mid-plane, independent second-direction termination, Through All / Both, Up to Face / Offset from Face, Up to Vertex, Up to Next and Up to Body in their supported geometry domains, plus start offsets, reversal, sketch-normal associativity, thin-wall thickness modes and straight-profile draft. Revolve adds reversal, midplane, a second angle, start angle and thin sections. Extrusions, revolves, solid lofts and sweeps provide New Body, Merge, Remove and Common modes with body scope. Solid lofts retain compatible holes/multiple regions, selectable boundary-vertex connectors and endpoint normal/direction influences. Solid sweeps retain exact supported sketch paths, path limits/reversal, placement, roll, rational twist, and fixed or supported tangent-following orientation. Modify includes fillet, chamfer, shell, draft, move/rotate, scale and body combine; Pattern includes linear, circular and mirror. The geometry bounds are listed below.
- **Reference → Plane / Axis / Point / Coordinate System** creates associative construction features. Reference Point on Edge retains the model edge and a scalar native parameter, with Start, Parameter midpoint and End controls; it measures parameter position rather than arc-length fraction. The same point sources drive datum constructions, coordinate origins, feature centers and mate frames. Coordinate systems use a point origin and two independently selected directions, with axis assignment and reversal; they publish a right-handed triad and XY/XZ/YZ planes. Pick a coordinate plane to sketch on it. Datums and coordinate-system elements can drive revolve/pattern axes, mirror/draft planes and assembly frame selections. Their docked fields use the same validated preview, Apply, Cancel and undo path as modeling features.
- In a sketch, click a member, endpoint, center, origin or axis in the model viewport for its action menu. Shift-click adds entities. **Smart Dimension** (**D**) infers lengths, signed offsets, angles, circle diameters/radii, arc radius/length/included angle and ellipse sizes. Enter units or a named parameter expression and watch the dependent preview before Apply. **Driven / reference** measures current geometry without imposing a solve equation. Dimension labels can be clicked to edit or remove, and dragged to position; Dimensions/Relations visibility is adjustable. **Create Named Parameter** creates an editable D1, D2, etc. variable. Relations include horizontal/vertical, coincidence, point-on-curve, parallel/perpendicular, equal lengths/radii, concentricity, exact supported curve tangency/curvature contact, midpoint, arbitrary-axis symmetry, axis alignment and fixed positions. Contact parameters can be fixed or solved on the actual curve. Select a point and Origin/X Axis/Y Axis to relate or dimension against the sketch frame.
- In **Select / Move**, drag endpoint, center, arc-through-point, or spline control handles directly on the sketch. Select a member to reveal move handles, circle radius handles, and ellipse major/minor radius and rotation handles; **Drag Handles** in the click menu returns to this mode while retaining selection. Constraints remain active during movement. Dimension/parameter-driven sizes are locked with an explanation. **Alt** bypasses grid snapping, **Esc** restores the drag's starting state, and **Undo Sketch Change** reverses one complete drag. Release keeps the result pending until **Apply**; **Cancel** restores the whole sketch operation. New rectangles retain horizontal/vertical relations without automatically fixing their position or size. Center rectangles also have a center handle on a construction diagonal.
- Sketches, bodies, selections, and feature previews share one model viewport. Finished, unused sketches remain visible and selectable on the model; double-click their contours to edit. Tool editors occupy the property manager in the main workspace.
- Click actual model faces or edges to open a compact action popup beside the selection and show a value/measurement leader. Edges offer Fillet and Chamfer; faces offer Sketch on Face, Shell (remove face), and Draft. Unavailable actions explain their prerequisites. Geometry is preselected in the chosen editor. Escape or clicking outside dismisses the popup. Geometry clicks during an active operation continue selecting inputs and expose available viewing actions; new operations explain that the current operation must be confirmed or cancelled. Sketch geometry and dimension annotations in the model viewport use contextual actions too. Empty-space clicks clear the selection without opening a menu; tree, History, graph and property controls select without an automatic popup. The view cube selects Front/Back/Top/Bottom/Left/Right/Isometric views. Pin assembly references to keep labeled components visible while editing; use Ghost others, Hide others, and Finish Editing in the viewport. **Tab** cycles overlapping candidates. Use the component selector and **Assembly** editor for in-place editing, isolation, reference pins, shared instances, placement expressions, configurations, and mates.
- The default workspace uses a top menu and **Features / Sketch / Assembly / Evaluate / Graph** command tabs, a left feature tree or property manager, one model viewport, and a bottom status bar. Single-click a sketch or feature in the tree or graph to select it; History clicks inspect the cached stage. These selections do not open a popup. Double-click a feature to edit it; right-click exposes grouped modeling, editing and viewing actions. Consumed sketches appear under their modeling features. The **History** rail shows numbered stations; **Graph** opens draggable cards, explicit dependency links and ports, named parameter branches, and an Assembly scope for components and mates. Graph positions, pan and zoom are presentation data. Feature source is available under **Advanced Source**; full document source is under Workspace.
- In **History**, click a station to display the model immediately after that feature, using cached geometry. Later features stay in the tree, dimmed, and do not appear or remain selectable in the viewport. **Latest model**, the viewport **Latest** button, or **Esc** returns to the current model. Inspection changes no definitions, draft, or undo history and sends no rebuild request. Double-click/Edit leaves inspection and opens the normal feature editor. History uses the current parameter values; Git revision comparisons remain a separate workflow.
- Feature-tree **Move Up / Move Down** edits authored order only when all explicit construction dependencies remain valid. The worker previews the reordered source; Apply waits for current validation and commits one undoable change, while Cancel restores its checkpoint. Source order is shared across configurations. Drag/drop, editable rollback/freeze and automatic reference retargeting remain work.
- **Workspace → Layout and theme** edits the rail, top, graph and semantic collection compositions. Fields, commands, menus and native controls share stable bindings and CSS styling. Collections discover matching features/commands; user-defined hierarchy controls scrolling, clipping, gaps, alignment and anchors. Import/export a portable presentation package, save a personal default, or save with the project. External files reload atomically after validation, preserving CAD drafts and the last usable presentation on errors. **Size** controls UI scale and toolbar height; drag the rail divider to resize. **F9** recovers the bundled UI; `--reset-ui` bypasses persisted overrides. See [presentation contracts](docs/presentation.md) for customization and extension registration.
- Save a project directory containing `project.json`, `parts/`, and `assemblies/`. Imported STEP resources are content-addressed. **File → Recover local work** restores committed and draft snapshots after a crash, including unsaved projects.
- Export the committed model to STEP, STL, PDF, DXF, or BOM CSV. Native sheet stock starts from closed sketches and supports tabs, straight edge flanges, linked formed/flat output and exact supported flat-pattern DXF with bend lines. Weldment groups use sketch sections and paths, profile placement/roll, planar end trimming, miter/butt corners, end caps and sketch gussets. Cut-list CSV derives native member centerline lengths and cut angles from evaluated geometry with configuration/quantity metadata. Existing bent-strip and structural-member definitions remain readable. Drawings have scoped sheets, orthographic/isometric/section/detail views, notes, linear dimensions, parameter-linked dimension labels, and title metadata. Saved annotations include dimensional tolerances, datums, GD&T frames, leaders and center geometry; the Drawing editor previews the sheet in the shared viewport.
- **Design → Component libraries** links local projects using exact pinned source snapshots. Check for updates and preview them explicitly; make an instance unique before editing a linked definition. Source resources remain available offline.
- **Assembly → Mates** offers standard locating/orientation mates, Width, Symmetry, travel limits, Profile Center, Linear Coupler and Path, plus Hinge, Gear, Rack and Pinion, Screw, Universal Joint, Slot and Cam / Roller relationships. Select associative component geometry and configure task-specific fields in the docked manager. Exact frames/carriers, full nested occurrence paths and active configurations drive the worker solve. The current preview reports residuals, equation rank and local component motion/DOF before Apply. Mechanical zero frames are captured from a current validated placement; unsupported sources fail explicitly.
- Use **Workspace → Versions** for local Git initialization, commits, branches, status, history, revision comparison, fetch, and push. Comparisons overlay the previous geometry in blue and show entity-level changes. The CLI also supports validated three-way semantic merges.
- **File → Create release** makes an immutable directory with the source snapshot, STEP/STL/PDF/DXF/BOM artifacts, backend identity, tolerance, and SHA-256 manifest. An existing release directory is never overwritten.

Two-finger scrolling orbits freely through 360 degrees in both directions, including over the poles; Shift pans; pinch or Command/Control + scroll zooms. A one-finger drag also navigates outside sketch mode. In sketch mode, clicks draw on the active plane, two fingers pan, and Shift orbits. **Normal To** aligns the view with the sketch plane. **F** fits the assembly or its sketches, **Shift+F** fits the active part, **Alt** temporarily reveals the assembly, **Command/Control+Enter** confirms, **Esc** dismisses selection actions, stops the current sketch tool, or cancels the operation, **Command/Control+K** opens command search, **F5** restarts geometry evaluation. **Command/Control+N/O/S/Z** create a part, open, save, and undo. Controls exposes sensitivity and an alternate pan profile. Gesture phases are synthesized where the platform does not provide them to the widget integration.

## Headless use

```sh
./target/debug/tcad new /path/to/project --sample
./target/debug/tcad validate /path/to/project
./target/debug/tcad export /path/to/project /path/to/assembly.step
./target/debug/tcad edit /path/to/project /path/to/command.json
./target/debug/tcad bom /path/to/project --output /path/to/bom.csv
./target/debug/tcad diff /path/to/before /path/to/after
./target/debug/tcad merge /path/to/base /path/to/ours /path/to/theirs /path/to/merged
./target/debug/tcad import /path/to/project /path/to/purchased.step
./target/debug/tcad release /path/to/project /path/to/new-release
./target/debug/tcad link /path/to/project /path/to/component/project.json
./target/debug/tcad describe /path/to/project
./target/debug/tcad git /path/to/project status --short
```

`validate` is a user-facing document/constraint/B-rep evaluation command. It is not a code test suite. An edit or merge is evaluated before being saved.

- **Hole / Counterbore / Countersink** start from explicit position-sketch points. A planar-face command starts a Point sketch on that face; Finish returns to the requested hole manager. Blind/Through All, head dimensions, start offset and entry direction preview through the shared worker. Multiple disjoint holes in convex planar stock preserve exact circular rims; other cases use the Boolean path with explicit validation limits.
- **Scale** has uniform or independent XYZ factors, an associative center and optional source-body retention. Body patterns have two linear directions, skipped positions, total/instance circular-angle spacing and fixed-orientation copies. **Curve Pattern** adds saved paths, parameter or supported exact-distance spacing, range/reversal and fixed/tangent orientation. **Sketch Driven / Table Driven Pattern** uses explicit associative points or expression-based coordinate rows, per-row rotation and skips, plus local CSV import/export. Surviving copies retain their construction identities. See [curve patterns](docs/curve-patterns.md) and [placement patterns](docs/placement-patterns.md).
- **Rib** grows open sketch contours onto proven bounded supports with parallel/normal fill and thickness placement. **Move / Offset / Delete / Replace Face** edits convex planar supporting faces. **Keep / Delete Bodies** filters whole solids by picked construction faces, including empty results. The limits are recorded in [ribs](docs/ribs.md), [direct editing](docs/direct-edit.md) and [body filters](docs/body-filters.md).
- **Composite Curve / Curve Through Points / Helix–Spiral** create saved reusable reference paths in the model viewport. **Ordinate / Baseline / Chain Dimensions** constrain planar X/Y sketch targets with a saved datum/order and draggable annotations. Datum planes add both angular bisectors and tangent planes on proven bounded rational patches or cylindrical/conical faces. See [reference curves](docs/reference-curves.md), [dimension groups](docs/sketch-dimensions.md), [equation curves](docs/sketch-equation-curves.md) and [reference geometry](docs/reference-geometry.md).
- **Drawings → Add Table** creates BOM, revision, bend, designed-hole, native weldment cut-list or general tables with editable paper placement, widths, row/text sizes and reserved view space. **BOM Balloon** links to the same configured item number and optional quantity. The paper preview, PDF and drawing DXF share these vectors. **File → Export Flat Pattern DXF / Cut List CSV** exports evaluated fabrication data; releases include it when present.

## Implementation limits

This is an integrated implementation with real modeling and exchange paths. It is **not a claim that the entire professional CAD specification is complete or release-qualified**. The current bounds are explicit:

- Sketch relations include fixed coordinates, coincidence, bounded point-on-curve, midpoint, arbitrary-axis symmetry, horizontal/vertical, parallel/perpendicular, equal lengths/radii, concentricity and arc-center relations. Tangency and curvature contact evaluate actual line/arc/circle/ellipse/Bezier/positive clamped NURBS carriers with saved fixed/free parameters; zero tangents and non-C2 curvature locations fail. Driven/reference dimensions retain their authored expression and measure the solved geometry without an equation. Smart Dimension includes coordinates, lengths, gaps, angles, arc length/included angle and circular/elliptical sizes. Ordinate, chain and baseline groups support X/Y targets with driving/reference entries; oblique, radial and angular groups remain work. The scaled damped SVD solver reports rank/DOF and rejects invalid trials; positional/angular acceptance remains 1e-6 mm / 1e-8 rad. Interpolating/control-point rational splines support up to 64 points and degree 1–15 with positive weights and editable clamped knots. Equation curves convert degree 1–15 parametric polynomials algebraically to exact Bezier controls, retaining a draggable constraint-aware anchor. Nonpolynomial/implicit equation curves, periodic/surface sketch splines and spatial sketch relations remain gaps. Mixed contours retain exact B-rep curves, while planar classification uses derived samples; crossing/touching material contours remain rejected.
- Convert Entities projects exact lines and supported positive-weight B-spline/NURBS edges from the active part. Missing/ambiguous edges, changed control topology, cyclic references, collapsed projections and implicit intersection/parameter curves fail. Offset supports nonbranching line/arc chains, circles and proven exact straight/circular Bezier/NURBS or degree-one polyline carriers; general ellipse/spline parallel curves remain unsupported. Fillet supports line–line, line–arc and arc–arc tangent corners with a bounded minor arc and one saved fillet per source arc; general spline fillets remain work. Chamfer supports straight corners. Trim/Extend/Split retain supported exact carriers; authored spline/conic/slot intent requires explicit Detach before destructive trimming. Repair adds coincidence only for mutually unique independent near endpoints and can remove exactly duplicate relations; it does not resolve ambiguous gaps or driven-endpoint conflicts. Stretch moves explicitly selected independent controls with relations active. Replace preserves the target member ID and compatible control/end-point references; incompatible references require repair. All member types can be construction geometry.
- Associative sketch mirrors, linear/circular patterns and affine copies retain source relations, with dynamic enrollment of newly drawn members, generated-instance suppression and extra affine placement. Patterns are bounded to 2–256 copies and 4096 source/copy entries; cyclic feedback and control-topology changes needing detach fail. Direct move/rotate/scale/stretch retain existing relations. Rho conics, parabolas, ellipse arcs and curved slots remain editable. Sketch Text imports pinned static TrueType/OpenType/collection fonts into exact polynomial outlines, with em-height, offset, rotation, tracking, alignment, multiline layout and a draggable anchor. Limits are 32 MiB per font, 1024 characters and 32768 outline segments. Kerning, ligatures, combining marks, bidi/context shaping, variable/color-only fonts, path text and automatic outline healing remain absent. Text edits preserve compatible IDs and reject retiring referenced contours. Associative local sketch blocks retain exact source controls/internal relations and multiple instances with parametric translation/rotation/positive uniform scale, construction/suppression, draggable anchors/local controls and exact Explode. Stable output mappings preserve compatible references. Local limits are 4096 source members, 65536 controls and 256 instances per sketch. Portable self-contained block files support cross-document import/export and explicit same-resource updates with pinned provenance and stable source/output mappings. Portable resources have a 16 MiB/512-control/128-relation/16384-work admission bound. Nesting, library indexing/browser, scale solve variables and full local drawing-tool authoring remain work.
- Extrude, Revolve, Loft and Sweep expose stable Selected Contours from native outer-boundary members or supported thin chains, retaining holes and rejecting stale/ambiguous selections; explicit selected order controls Loft correspondence. Legacy ordinal connectors require an explicit native anchor before selected-region use. Extrusion provides associative model/datum point starts and independent end conditions/body scope, including planar oblique Up to Face/Offset from Face, stable sketch-point Up to Vertex and Up to Next/Body when one fully covering forward cap is proved. Curved termination requires a complete finite clamped positive-weight rational four-sided patch over a rectangular straight section normal to the extrusion, with proved monotone projected coordinates and separation; holes, existing trims, overlapping candidate branches, piecewise target coverage and curved normal offsets fail. Thin extrusion uses line/arc/circle offsets with one-side/two-side/midplane thickness and flat ends. Drafted extrusion requires a straight profile, normal direction and compatible planar caps.
- Revolve supports reverse, midplane, independent second angle, angular start and thin sections, with total extent at most one full turn. Exact carriers and shared partial caps are constructed from solved sketch members. Control hulls must prove one axis half-plane; only one connected stationary boundary chain may meet the axis. Internal path/knot poles, isolated/multiple pole contacts, holes touching the axis and the native near-axis uncertainty band are rejected. Constructed walls and angular edges use member/endpoint/station ancestry, and nonzero start angles are applied exactly.
- Solid lofts support ordered parallel planar sections, compatible holes/multiple regions, boundary-vertex connectors and normal/direction endpoint influences. Matching material-contour families and strictly advancing sections remain required; native edge counts may differ and exact common-denominator carriers remove the old normalized-weight restriction. An exact affine/convex/nested-circle separation proof, or a complete angular-derivative proof for supported single-contour circle/polygon and star-shaped families, guards intermediate sections. Endpoint controls must retain positive axial progression; arbitrary guide curves, nonparallel sections, general boundary lofts and global smooth continuity remain work. Solid sweeps accept exact supported open sketch chains or one native circle/arc, path limits/reversal, source/path-start placement and roll. Fixed sections require positive control-hull progression through every section plane. Twist uses an exact rational half-angle law per retained path span, not uniform angular speed. Tangent following supports collinear paths or native circular paths with positive radial clearance and zero circular twist; general spline moving frames, composite/spatial transport, guides and arbitrary self-intersection trimming remain gaps. Thin loft/sweep sections use the supported line/arc/circle offsets.
- Shell supports inward/outward and per-face thickness on proven convex supporting-plane stock, plus proven concave straight/circular prisms with through holes, contour/cap thickness overrides and end-cap openings. Contained disjoint cylindrical blind/through pockets have an inward-shell path. Offset envelopes must stay separated: pocket/pocket, pocket/wall and blind-floor collisions require additional trimming and fail explicitly. General curved shells, intersecting offsets, arbitrary side openings and unrestricted multi-thickness prism contours remain work. New wall/rim references retain constructor/source ancestry. Neutral-plane Draft remains restricted to convex unsplit straight planar stock; parting-line and curved/concave draft remain work.
- Blind pockets and through-openings wholly inside a convex planar body preserve their analytic profiles and shared boundary topology, including rotated and polygonal extrusions. Positive-weight control hulls prove containment; intersecting sides, existing pockets and unsupported boundaries use the general Boolean path. Convex straight edges between supporting planar faces support equal-distance, two-distance and distance/angle chamfers with an optional associative distance-1 face, including adjoining edges. A convex polygonal through-cut can remove a corner with one clipping plane. Native chamfers preserve old pockets/voids only with complete finite containment proofs; curved/concave selected edges and intersected curved pockets report unsupported geometry. Native constant-radius fillets cover the documented convex straight/planar envelope and supported adjoining-edge corners. General Boolean cuts use the kernel path when native planar construction is ineligible. Curved Boolean boundaries validate their actual intersection curves and supporting surfaces rather than rejecting their guide polylines; failed projections, inconsistent endpoints or open shells still block confirmation.
- Separate surface bodies support planar/extruded/revolved/ruled-loft/fixed-orientation-sweep authoring, exact four-boundary Euclidean Coons Fill including positive variable-weight rational curves, with bounded degree-16 algebra and a globally injective rational projection certificate, and coplanar-shell signed offset/Thicken. Directed ruled strips retain exact supported native rational edges and associative direction/length; matching planar/rational mid-surfaces retain source references, explicit correspondence/fraction and conservative coefficient guards. Planar Sketch Trim retains Boolean curves; parameter-domain Trim derives exact U/V boundaries while preserving the original finite rational carrier for Untrim. Untrim rejects infinite planes, collapsed patch sides and periodic seams. Extend shifts all or selected straight edges on independent convex planar faces. Native surface extrusion cannot sweep implicit intersection/parameter boundaries; repeated trimming/thickening of those boundaries fails clearly. Knit can form a solid only from one closed oriented shell with matching rational boundaries and a 1e-10–1e-6 mm sew tolerance. Topology validation does not certify absence of general geometric self-intersections. Curved offsets/thickening, curved/mutual trim and extension, general boundary networks, gap healing and smooth boundary continuity remain missing. Fill boundaries retain authored source history; uncertified patches remain rejected.
- Mold features retain associative source intent. Draft Analysis reports exact planar normals against a pull axis and minimum angle, leaving curved faces unassessed; it performs no global undercut/release analysis. Planar positive/negative adjacency supplies parting edges, explicit rational edges form ruled strips perpendicular to pull, and closed coplanar loops form planar shut-offs. Shrink applies positive independent XYZ factors around an associative point with mapped topology provenance. Tooling Split creates core/cavity bodies by subtracting the part or shrink output from sketch stock split by a parallel plane. Curved parting/shut-off networks, stock containment/release certification, side cores and broader mold organization remain gaps.
- Topology references retain producer/owner, authored source closure and constructor roles. Geometric signatures are diagnostics, and temporary kernel IDs only join actual construction history. Generic Boolean intersection curves with known constructed carriers use surface-carrier ancestry; ambiguous authored carrier matches and disconnected edges sharing the same carrier pair fail instead of receiving position-based names. Legacy or unknown carriers retain compatibility fallbacks. Split/merged topology can require reselection. Full topology history and every persistent-reference case remain unsolved.
- Reference planes, axes, points and coordinate systems use application-owned f64 definitions and configured history-aware display/picking. Model-edge point sources evaluate the stored native bounded carrier with a scalar 0..1 expression, require consistent finite endpoints and construction provenance, and retain orientation independently of incident faces. Coordinate systems publish a right-handed origin, three axes and three sketchable planes. Axis sources include proven straight/circular model carriers, solved sketch members and supported analytic revolution/rational ruled cylinders or conical frustums. Both angular bisectors and tangent planes are associative. Tangent planes require a proven untrimmed rational four-sided patch or bounded cylindrical/conical carrier, with regular derivatives and in-domain anchors; general trims/periodic faces and broader inverse-point carriers remain work. Composite and linear/natural-cubic point curves retain exact source intent. Helix/Spiral supports constant pitch, taper and up to 256 turns; zero-pitch constant-radius circles use exact rational arcs. Analytic helical solid sweeps, projected/on-surface curves, independent B-rep vertex/arc-length point modes and mass-center origins remain gaps. Native curve display uses fallible carrier evaluation and tolerance-driven subdivision; general parameter/intersection-curve chord errors are estimated, without a global certificate.
- Assembly mates include standard locating/orientation modes, Width, Symmetry, Limit Distance/Angle, Profile Center, Linear Coupler and Path, plus Hinge, Gear, Rack and Pinion, Screw, Universal Joint, Slot and Cam / Roller. Sources resolve exact planar faces, supported rotational/straight/circular carriers, datums/coordinate frames and sketch geometry through complete configured/nested occurrence paths. Profile Center integrates one planar material region; Path/Cam use exact planar carriers and local contact, while Slot requires a line/circle center path. Principal angular coordinates are limited to ±180 degrees; continuous multi-turn winding, general 3D/composite paths, spherical/curved-surface mating, global collision exclusion, mate-aware dragging and flexible subassemblies remain work. Bottom-up placement solving precedes in-context rebuilding and rejects feedback cycles. Residual/rank/nullspace reports describe local infinitesimal freedom, not finite reachability or dynamics. Pinned libraries and update previews exist; reusable feature graph groups and third-party feature hosting remain gaps.
- Named and derived part/assembly configurations retain inherited parameter, typed feature-expression dimension, suppression, material, property, component-configuration and BOM overrides. Dimension columns support stable feature/record IDs and field-by-field inheritance; anonymous arrays remain positional. Sketch dimension columns and non-expression counts remain work. Local JSON/CSV design tables and stable linear/circular component patterns are editable in docked managers. Simultaneous subassembly variants resolve independently; conflicting occurrence equations, flexible assembly solving and mirror component patterns remain unsupported. Complex selections can require editing the source representation.
- STEP imports supported solid models and bounded shell-based surface models, including mixed solid/surface parts and rigid assembly structure. Surface import retains pinned model/shell/face/edge entity ancestry and rejects incomplete conversion, unsupported representation items or ambiguous trim intent. Its current carriers are planes and proven full natural rational patches; arbitrary periodic/swept/trimmed surface carriers remain work. Placements must be finite, affine and rigid; unit contexts must have finite positive homogeneous length scales. Original resources remain pinned. Supported open shells can be exported alongside solids; broader neutral/native translators and geometric healing remain gaps.
- Native sheet stock supports sketch regions/holes and positive/reverse/midplane thickness. Tabs precede bends; edge flanges require complete supporting straight base edges, positive inside radii and signed angles through 90°. Developed flange envelopes must not overlap. Formed/flat B-reps and bend lines share thickness/radius/angle/K-factor expressions; exact DXF cutting curves fail clearly for unsupported intersection representations. General solid recognition/unfolding, corner relief, hems/jogs and swept/miter flanges remain absent. Native weldments support planar straight sketch paths and solid/hollow sections, two-member miters, independent butt ends, associative planar end trim/extend, terminal end caps and sketch gusset stock. Curved/spatial members, general body trimming, physical weld beads, maximum blank dimensions and cap/gusset cut-list rows remain absent; reported member lengths are centerline lengths.
- Drawings share f64 paper vectors between the main-viewport preview, PDF and DXF. Dimensions include aligned/horizontal/vertical/angular/diameter/radius and authored simple/counterbore/countersink hole callouts, associative sketch/edge/planar-face references, explicit units and symmetric/deviation/limits/basic tolerances. Datum identifiers, geometric-tolerance frames, material modifiers, leaders and center marks/lines are saved semantic intent. Surface-finish and weld symbols add editable bounded ISO/ASME/AWS convention subsets with shared paper vectors and explicit quantity units; full standards libraries/certification remain absent.
