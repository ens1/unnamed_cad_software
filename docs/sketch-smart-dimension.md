# Smart Dimension selection and value entry

Smart Dimension enters a persistent entity-picking mode in the active sketch. Pick a circle center handle and a straight sketch member or model edge, in either order, to open perpendicular-distance value entry in the docked property manager. The first entity remains selected while the second is picked. Picking one circle alone waits for another entity; press **D** with that circle selected to enter its diameter. Single lines retain their length and axis-aligned coordinate choices, and points retain their coordinate choices.

Outside pick mode, Command-click or Shift-click two sketch entities, then invoke Smart Dimension. A circle member paired with a straight member is resolved to that circle's actual saved center point. A Command/Shift-selected model edge can accompany a sketch point or member; its native edge reference remains transient until Smart Dimension is invoked. Primary multi-selection clicks do not open automatic context menus. Normal single geometry selection and explicit secondary selection retain contextual actions. Secondary-clicking an entity already in a multi-selection preserves the pair, so contextual Smart Dimension uses the same pair as the toolbar.

During dimension picking, sketch handles and annotations accept selection without starting a handle or label drag. Enter a length with explicit units, such as `1 in` or `25.4 mm`, or a named parameter expression. Values preview in the shared sketch draft. **Done · Pick Next Dimension** retains the current preview and clears its selection for the next pair. Picking a new geometry while value entry is open also starts the next pair and retains the preceding preview. **Apply Sketch** commits only the current validated document evaluation as one undoable sketch edit.

**Cancel Dimension** or Escape restores the source, local history and shared draft that existed when that dimension was started. This includes any automatic model-edge conversion and newly promoted named parameter. Earlier sketch edits remain. Escape after Done exits picking while retaining accepted previews. Switching to another sketch drawing or editing tool accepts the current preview and clears transient dimension state. Whole-sketch Cancel continues to restore the modeling operation's original checkpoint.

## Exact distance intent

The saved constraint kind is `point_line_distance`, with entities ordered as `[point_id, oriented_line_id]`. For a circle paired with a line, `point_id` is the circle's existing center ID. The line carrier is unbounded: the perpendicular foot can fall beyond the finite member endpoints. The saved positive distance is perpendicular distance to that carrier, rather than endpoint distance or an offset from the world-picked cursor.

New picked dimensions save `distance_side: "left"` or `"right"` relative to the exact line's start-to-end orientation. The driving equation preserves this side through changes, including a zero gap, and does not infer a new side on subsequent edits. Reflecting both the center and oriented line in a source member move flips the saved side; positive-scale block placements preserve it. The optional field is omitted for older constraints, which retain their unsigned-distance equation until new picking explicitly supplies side intent. Duplicate-relation repair includes the side in its equality check.

Driving dimensions add native solver residuals. Driven/reference dimensions measure current exact solved geometry, retain their saved expression and side for returning to driving, and add no residual. The current selection, source constraint, unit, expression, error and mode are exposed through semantic editor data independently of theme/layout. On-model annotations show the center-to-foot witness and the dimension value.

## Model-edge references and limits

Automatic edge references require a unique current native owning body and the same active part occurrence. The producer output must precede the sketch; normal document validation also rejects cyclic dependencies. Only exact degree-one, two-control-point native model edges are admitted. Their exact projection into the authoritative sketch plane becomes an associative construction line with independent control IDs, so a coincident free center does not accidentally become a driven edge control. New linked conversions save `construction_orientation: true` and follow the absolute native edge carrier orientation, independently of incident-face boundary ordering. Matching line conversions with this flag are reused. Older conversions omit the field and retain their historical incident-face orientation; dimension picking creates a separate independent reference instead of silently changing those source IDs. A projection that collapses to a point is rejected.

The linked source retains owning body and native topology references and updates with the model through Convert Entities evaluation. A lost, ambiguous, changed-type or suppressed edge is reported by source/native validation rather than replaced with sampled geometry. Model-edge conversion presently targets the active part's solid mesh edges; reusable reference-curve picking and curved model-edge distances are outside this automatic workflow. Two preselected model edges without a sketch point/member are not accumulated as a pair. Circle-center to sketch line, circle member to line, point to line, and point/line universe-axis dimensions use the existing exact native contracts. Additional curve-distance/closest-point dimension families remain unsupported.

Solver implementation fingerprint: `tcad-native-lm/11`. No code tests, probe programs or manual UI acceptance were run for this change; integration compile/lint/package is handled centrally and interactive acceptance remains with the user.
