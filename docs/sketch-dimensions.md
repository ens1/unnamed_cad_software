# Grouped sketch dimensions

TCAD saves ordinate, baseline and chain dimensions as editable native sketch intent. These workflows support planar horizontal X and vertical Y coordinates of current native sketch points, including construction controls, generated controls and text/block anchors. Member selection expands to open-curve endpoints or circle/ellipse centers. The sketch origin can be the datum. Each group retains its datum, direction, ordered targets, native constraint identities and annotation layout.

Select points with Shift, then use Sketch → Dimension Groups. The first selected native point is the initial datum; selecting Origin uses Origin instead. Targets can also be added from the docked point list or the current viewport selection. The property manager changes the datum and direction, reorders or removes targets, edits each unit-aware dimensional expression and switches individual entries or the entire group between driving and reference. Direction, datum and ordering changes retain the authored values and change the native equations; they do not silently replace the dimensional intent with a new measurement.

Ordinate dimensions measure every target from the common datum and display a zero datum with stepped leaders. Baseline dimensions measure from the same datum with stacked dimension lines. Chain dimensions measure successive pairs in the saved order. Signed values follow the selected positive sketch direction. The geometric equations are the native `distance_x` or `distance_y` constraints; the group does not add hidden duplicate equations. Reference entries measure current solved geometry without adding equations, retaining their driving expression for later restoration. Named parameters and ordinary sketch relations remain active.

The viewport draws extension lines, arrowheads and labels on the actual sketch. Double-click a group label or its zero datum to edit the group, or use its on-click Edit/Delete Dimension Group actions. Dragging an entry label starts the same shared group editor and saves its offset in sketch-plane millimeters. Offset, spacing and individual label offsets also have docked fields. Accept requires the current validated worker result; Cancel restores the starting checkpoint. The whole accepted group operation contributes one local sketch undo entry. Apply Sketch commits through the common document history.

When an equation is unsatisfied, its group label can show the actual native residual in red. This identifies equations with a residual above the native millimeter-equivalent tolerance; it does not claim a minimal conflicting set. The existing numerical degree-of-freedom report remains available.

Deleting an entire group removes its native dimensions. An explicit native edit that retires a group target, datum or dimension releases that group's grouping metadata; surviving equations remain ordinary dimensions. A broken chain is never silently reordered or reconnected. New source with missing or incompatible native identities is rejected by validation.

The application-owned dimension contract is `tcad.sketch-dimensions` version 1. Its omitted-empty `Sketch.dimension_groups` map preserves older sketches' serialization. A group stores kind, datum point, X/Y axis, ordered target/constraint bindings, signed overall offset, positive spacing and optional per-entry label offsets as f64. The native constraint owns the unit-aware expression and driving/reference state. Semantic elements publish the group, relationships, native equations and f64 annotation geometry separately from the renderer; theme roles and classes control the default presentation. Library imports remap group, point and constraint identities.

Suppressed geometry cannot become a new datum or target. Saved groups retain their entries, values and original chain stations across suppression; annotations and selection include only equations whose actual source entities are active. A hidden chain entry does not reconnect its neighbors. Fully inactive groups publish their saved intent with a suppressed state and no selectable annotations. Restoring the source restores its original dimension identities.

Bounds are 1–128 unique targets per group, finite positions and layout, and positive finite spacing. Arbitrary oblique/projected directions, radial/angular ordinate or chain families, independent dimension-datum feature objects, automatic overlap avoidance, dragging the zero datum, minimal-conflict repair and graphical null-space DOF arrows remain unsupported. No tests or interactive acceptance exercises were run; compilation and lint are handled by the integrated build, and user acceptance remains pending.
