# View navigation

Navigation preferences are application-owned presentation intent, contract `tcad.navigation/1`. They never modify CAD definitions, solver inputs, source fingerprints, or modeling undo. The desktop saves preferences atomically in the user TCAD support directory inside the unified `settings.json`; valid legacy `navigation.json` preferences are migrated when that unified file is absent. Saved project workspace presentation also carries a navigation copy. The user preferences override the project's preference copy at startup. New/Open and leaving Edit in Place preserve the current user's preferences. Invalid versions, nonfinite values and out-of-range sensitivities restore defaults. F9 restores default layout, styling and navigation preferences and clears view roll; `--reset-ui` bypasses saved presentation and application preferences for that launch. Open Edit/Tools → Settings… (Cmd+,) and choose Application → Trackpad and navigation; changes preview with Apply/OK/Cancel. See [settings](settings.md).

The default two-finger scrolling orbit reverses both axes from the previous implementation. Outside sketches, two fingers orbit and Shift pans; the alternate profile makes two fingers pan and Shift orbit. Sketches default to pan and Shift orbit. Horizontal and vertical orbit/pan inversion are independent. Orbit crosses both camera poles without an angular stop. Camera roll, renderer, projection/picking rays, pan and cursor-anchor zoom share one analytic camera frame. Named views and Normal To clear roll. Upright removes roll and restores an upright equivalent orientation while preserving the eye position and target.

Pinch zoom anchors at the starting cursor on the camera target plane, rather than moving the pivot to whichever face the cursor crosses. Ctrl/Command scrolling and ordinary line-unit mouse wheels zoom once through the same bounded distance control. Native rotation rolls the view when enabled; disabling it permits concurrent scroll to follow the ordinary orbit/pan profile. Native smart zoom fits the current selected full occurrence path, or the complete displayed part/assembly when there is no selected geometry. `Shift+F` fits the selected occurrence; without a selected occurrence it retains the active-definition fallback. These are display fits, so History, isolation and exploded display bounds follow their current presentation.

The docked Controls editor and command search expose profile, inversion, orbit/pan/zoom/roll sensitivity, precision multiplier/modifier, native rotation and smart-zoom settings. Alt reduces navigation speed by default; Alt+Shift or no precision modifier can be selected. Alt retains the existing assembly peek behavior. On-screen orbit/pan/zoom, fit, upright and stop buttons provide explicit alternatives. Preferences, typed ranges/options and stable `navigation.*` commands are also published through `navigation-preferences` / `navigation-preference` semantic elements. For example, bind a custom component to `view:navigation:invert_orbit/0` or invoke `navigation.upright`; these use the same preferences and action handlers as the docked controls. Presentation layout and style do not define navigation mechanics.

A gesture captures its initial viewport, action, anchor and target. Modifier changes do not rebind the action mid-gesture, although the precision modifier can change speed. An actual phase End applies its final delta before releasing that capture; a new Start establishes new action intent immediately. Unphased wheel streams retain ownership until a 180 ms quiet interval. Gestures beginning over another panel cannot migrate into the model viewport. A click, Esc, editor/command transition, lost focus, cursor leaving the window, active sketch handle/drawing/annotation capture or text value focus stops navigation and suppresses trailing input until the stream ends and is quiet. A press frame never reacquires residual scroll. TCAD adds no generated inertia.

The platform adapter reads the pinned Winit 0.30.13 primary-window events, retaining the actual available phases/window identity and normalizing physical pixels for window/UI scale. The pinned Bevy 0.20 / bevy_egui 0.43.1 bridge otherwise loses scroll phases and broadcasts pinch; TCAD does not forward a duplicate pinch. Accepted explicit non-touch egui zoom/rotation events are fallback mechanisms, excluding Ctrl-wheel zoom smoothing and doubled native/emulated scroll. Native duplicate suppression follows chronological gesture segments; an End event does not reclassify a following scroll Start. The camera updates after the final egui navigation pass and before transform/camera propagation, keeping rendered geometry and same-frame overlays/picking aligned. Each UI frame consumes camera motion once even if egui repeats a layout pass. Input admission is limited to 256 events per frame and rejects nonfinite/unreasonable deltas.

Native pinch, rotation and two-finger smart zoom are available on macOS through this pinned stack. Winit exposes pinch/rotation/smart zoom on iOS and an iOS-only native pan, but TCAD does not currently ship an iOS app or enable its native recognizers. Other desktop platforms can provide high-resolution scrolling. Touchscreen camera gestures are currently unsupported: touch-generated primary-pointer events retain normal sketch/annotation ownership rather than being repurposed as a second camera capture. Actual touch contacts suppress camera navigation, including mouse emulation, and are never turned into synthetic pinch/rotate/pan. Dedicated native trackpad rotation/smart-zoom events are not supplied on Windows/Linux by this dependency version. macOS finger and momentum phases can be merged by Winit, and some cancellations are delivered as End; there is no separate reliable momentum flag or hardware cancellation guarantee. Per-device profiles, native gesture recognition settings, OS-generated inertia cancellation, and hardware/platform usability acceptance remain open. This source capability inventory is not a claim of interactive acceptance.
