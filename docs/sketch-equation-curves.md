# Polynomial sketch equation curves

Equation Curve authors an exact planar parametric polynomial in the current sketch. It saves ascending length-valued coefficients for X(t) and Y(t), a finite increasing dimensionless parameter interval, a unit-aware rotation, an insertion anchor, and persistent derived control identities. Each coefficient can use document parameters and normal unit-aware expressions. The docked editor provides degree, both coefficient lists, parameter limits, rotation, construction state and source-anchor selection/coordinates.

The coordinates are X(t) = X₀ + X₁t + … + Xₙtⁿ and Y(t) = Y₀ + Y₁t + … + Yₙtⁿ, followed by the saved rotation and anchor translation in sketch-plane millimetres. The implementation composes the polynomial algebraically with its parameter interval using Horner multiplication in Bernstein form. Multiplication by the linear Bernstein polynomial with the two saved parameter endpoints raises the degree exactly; the next power coefficient adds to every Bernstein control. The resulting native Bézier member contains no sampled curve fit or renderer geometry.

The source anchor is a normal sketch point and can be dragged or constrained to universe geometry or other sketch entities. An anchor may also reference another operation's generated point, in which case that source operation drives its position. Every Bézier control is an evaluated output of the equation and remains available to existing dimensions, snapping and source-reference workflows; controls cannot be independently dragged while the equation owns them. Coefficient/range/rotation edits and anchor drags use the common constraint solve, current worker preview and sketch operation checkpoint. Apply requires current validation; Cancel restores the starting source, and accepted edits use the common undo history.

The one output member and endpoint control identities persist across compatible degree changes. Existing interior identities are reused in order, and new controls have stable application-owned identities reserved from the member identity so repeated draft evaluation does not create new selections. Adding zero high-power coefficients preserves the polynomial; lowering degree changes its power law and retires unused interior controls. An edit that would retire a control referenced by local geometry, a relation, another sketch operation or a typed downstream feature/assembly reference is rejected. Dependencies must be explicitly repaired or detached first. Explicit detach retains the current exact native member and controls while releasing polynomial source ownership.

Source contract version 1 is independent of the native kernel, renderer, docked widgets and styling. Semantic elements expose the saved polynomial, typed coefficient/range/rotation expressions, source anchor, derived controls and contextual edit/construction/delete actions. Empty equation maps are omitted from native source serialization, and library import remaps output, anchor and control identities through the same sketch source mapping as other members.

Current bounds are one planar member of declared degree 1–15, matching coefficient-vector lengths, finite coefficient values and an increasing finite parameter interval whose difference and full algebraic conversion remain representable in f64. The complete Bézier control hull must stay finite, and constant/collapsed curves are rejected. Downstream profile operations still require the sketch's current validated closed material contours. Open curves can provide paths or combine with other exact sketch members. General trigonometric/nonpolynomial equations, piecewise laws, implicit equations, spatial equation curves and direct control dragging without detach are unsupported. Compilation/linting are integration evidence only; no tests, probes or manual UI exercises were run.
