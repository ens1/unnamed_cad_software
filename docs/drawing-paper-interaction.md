# Drawing paper interaction

Drawing contract 6, sheet-template contract 2 and paper-interaction contract 1 separate saved drawing intent from disposable selection geometry. Paper quantities stay in f64 millimeters; renderer pixels and handles are not source references. Version 1 templates remain readable.

The Drawings editor uses the main viewport for paper selection and editing. Select a view, dimension, annotation, table section or title cell on its actual vectors. Selection also opens the relevant compact property controls. Drag an item to move it; selected view/title-cell corners resize their paper rectangles, dimension handles move dimension offsets, and supported annotation handles move labels or saved leader elbows. View alignment uses projected model origins, a saved parent and horizontal/vertical/free alignment, with optional inherited scale. Cycles and invalid sources are rejected.

Paper Smart Dimension picks native geometry on an existing drawing view. Auto, aligned, horizontal and vertical modes accept two references; diameter and radius use proven exact circular carriers. Circular centers are explicit associative references and can be dimensioned to another point. Dedicated typed controls continue to author angular and designed-hole dimensions. Reference picking uses exact supported model curves, sketch controls and circular centers rather than treating rendered line samples as engineering authority. Tessellated section views do not acquire invented exact section references.

Attachment handles and Reattach controls replace the first, second, third or target reference, as appropriate. Exact circular dimensions and center marks offer carrier reattachment. An unresolved dimension, annotation, overflowing view or table remains an explicit diagnostic paper item during repair. Several errors can be corrected incrementally. Its placeholder is a selection aid only. Apply and exports still require every source reference to validate; a complete current native model evaluation is retained separately to make repair possible when only the drawing is invalid. Incomplete geometry never acquires that permission.

Drag previews update the shared drawing draft before Apply. Escape restores that gesture's starting document and fields while retaining earlier drawing edits. Whole-operation Cancel restores the editing checkpoint. Apply waits for the current worker identity and commits one undoable change. Competing source commands and field mutations cannot take over an active paper capture. Changes of focus, layout, scale, sheet or page invalidate obsolete hit geometry. A failed final drag proposal restores the gesture rather than silently accepting an earlier position.

Grid spacing is a paper length with explicit units; snapping can be enabled independently. Alignment guides are disposable paper aids. Pinch zooms around the cursor, two-finger scrolling pans paper, and Fit Sheet resets the paper camera. Table continuation pages share the same editor and exported page vectors; model views and their annotations live on page zero.

The semantic presentation publishes `drawing-interaction-field`, `drawing-paper-item`, source-owned handles and `drawing.interact-*` actions. The `drawing-interaction` value adapter enforces current document, sheet, page and editor identity. User compositions can place the same controls elsewhere. `drawing-sheet`, `drawing-toolbar`, `drawing-paper-item`/`drawing-paper-handle` states and the existing selection-color, handle-size and stroke-width style properties control presentation independently of engineering source. `drawing-paper-status`, `drawing-snap-guide` and `drawing-pick-marker` expose the new chrome and selection aids too. Drawing rectangles, title-cell dimensions and printed scales remain drawing intent.

Limits remain: exact hidden-line removal, general auxiliary/relative views, exact arbitrary sections/hatching, complete model-item import, annotation standards libraries and general topology repair. Source inspection, compilation, formatting and linting are implementation evidence; no code tests, probes or interactive acceptance runs were performed.

The 2026-10-11 delivery passed `cargo fmt --all --check`, `cargo clippy --workspace --lib --bins --locked -- -D warnings` and workspace compilation through `scripts/package-macos.sh`. The package script validated Info.plist and the nested executable/bundle signatures, then replaced `dist/TCAD.app`. No application launches or interactive checks were performed.
