# Standard hardware library

The Standard Hardware command inserts a sourced dimensional envelope into a chosen assembly. Hardware catalogs are optional Git content repositories; no catalog ships inside the application. Open **Libraries** to clone a repository or enable your own checkout before inserting catalog hardware. The separately maintained catalog version `2026-10-12.1` includes 32 entries: M3, M4, M5, M6, M8, M10, M12 and M16 in four families—DIN 125 Form A washers, DIN 934 hex nuts, ISO 4762 socket-head screws and DIN 933 hex-head screws. Each entry records its original supplier references and retrieval date.

Dimensions come from [Fuller Fasteners washer tables](https://fullerfasteners.com/tech/din-125-specifications-flat-washer-normal-series/), [socket-cap tables](https://fullerfasteners.com/tech/iso-4762-12474-specifications-hex-socket-cap-screws/), [DIN 933 tables](https://fullerfasteners.com/tech/din-933-specifications-hex-head-screws-fully-threaded/), and [A&D metric full-nut data](https://www.aanddfasteners.co.uk/uploads/media/CVwuYn-media-DIN934Fullnutspecification.pdf). Washer thickness and hex-head height use published nominal values; washer outer diameter and hex flats use maximum/nominal values. Socket screws use plain-head maximum diameter/height, nominal hex-key width and minimum socket depth. Nuts retain the supplier's DIN 934 pattern; M10/M12 across-flats values are not relabeled as their differing current ISO 4032 equivalents. Source conditions remain embedded in the catalog and copied part origin.

Every part begins with ordinary native sketches, including actual closed circle, concentric annulus or straight hexagon members and fixed point constraints. Standard Extrude, Join and Cut features create one final solid output. No primitive-creation command, duplicated overlapping body, bounding-box substitute or hidden geometry fallback is used. The geometry worker must validate the current result before OK commits it. Unsupported contact or pocket geometry is reported by the normal model evaluation; cancellation restores the insertion checkpoint.

Screws have an editable under-head length parameter. The shank extends in negative Z from the bearing plane at Z=0; the head extends in positive Z. Washers and nuts start at their bottom bearing plane at Z=0. Translation and rotation controls accept unit-aware expressions in the owning assembly's parameter scope. Material and visual finish are independent project selections. Existing occurrence placement and mate workflows remain available after insertion.

The library explicitly represents screw shanks as smooth nominal-diameter envelopes, and nut bores as smooth nominal-thread-diameter bores. Thread teeth, runout, tip chamfers, collars, head-face chamfers and edge blends are omitted. Socket pockets use a flat bottom. Mass calculations use the evaluated simplified geometry and the assigned engineering density; they are not supplier weights or certified threaded-part masses. The dimensional reference does not establish a fastener property class, procurement availability or full standards conformity. Offered length presets are common modeling lengths; custom lengths between 0.1 and 1,000 mm are allowed without claiming supplier stock availability.

Insertion reuses an existing source definition only when it exactly matches the original catalog-generated part, including its chosen material and finish. A part changed through sketching, parameters, features, configurations, metadata or appearance receives a separate definition on a later catalog insertion. An optional omitted-when-absent `Part.standard_part` snapshot retains the original dimensional source; it is provenance rather than certification of later edits. Linking namespaces native feature/sketch identities while retaining those catalog identities and citations as metadata. Make Unique preserves the original source snapshot and creates editable native definitions.

The dense browser, independent value fields, dimensions, source information, simplification disclosure and actions are semantic presentation elements. The authoritative contract is `cad_core::standard_parts`, version 1. JSON catalog parsing supports at most 4 MiB, 2,000 entries and 64 source references, with bounded portable identities, finite positive dimensions and consistent dimensional envelopes. Catalog contents do not fetch URLs or execute external content.

Enabled manifest entries with kind `standard_parts` point to the catalog JSON. Up to 32 hardware catalog files may be enabled at once. Repository refresh loads a new browser snapshot; it does not replace inserted component definitions. Every inserted part retains its original source version and complete dimensions/citations. Disabling or removing the repository does not affect saved parts. Duplicate entry IDs or conflicting citation IDs across enabled catalogs are reported, so one fork cannot silently shadow another. Disable overlapping sources or assign independent entries distinct IDs.

Original TCAD code and the selected factual data arrangement use WTFPL. Supplier publications, diagrams, product names and trademarks remain their owners'; source publications or logos are not bundled or relicensed. The library does not claim supplier endorsement.
