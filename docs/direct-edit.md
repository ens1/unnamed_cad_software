# Direct face editing

TCAD provides saved Offset Face, Move Face, Delete Face with healing, and Replace Face operations for proven convex straight planar solids. Select a model face and start the matching feature command. The docked property manager retains the owning solid output and explicit face construction references, allows several selected faces, and edits the operation through the shared feature draft.

Offset Face changes each selected supporting plane's signed normal distance; positive values move outward. Move Face applies a part-local XYZ translation and a rotation about an associative axis to the selected supporting planes. Replace Face uses an associative origin/datum/coordinate-system/model-face plane, initially orients its material side consistently with the old face, and provides an explicit reversal. Delete Face removes the selected supporting planes and heals the remaining faces by their exact intersections.

These operations reconstruct the finite intersection of the remaining supporting half-spaces. Vertices and straight boundary edges are shared by the resulting B-rep; unchanged faces retain their actual plane carrier. Edited faces and newly adjacent edges receive construction ancestry from the source faces and operation. The source definitions contain f64 unit-aware expressions and application-owned references, independently of renderer and kernel objects. Direct-edit source contract version 1 publishes quantities, references, supported geometry and available actions through the semantic presentation model.

Apply requires the current validated evaluation, and the operation must leave a closed, manifold, bounded solid with positive volume. Cancel restores the original checkpoint, and an accepted feature is one document undo operation. Direct editing consumes its source output and carries untouched solids in that output forward. Configuration suppression restores the predecessor body; cached History inspection remains view-only.

Supported stock has one convex outer shell, one unsplit planar polygon per supporting face, straight native edges, and no existing cavities. Each operation selects 1–256 distinct faces. Each edited source is bounded to 128 supporting faces, 256 native vertices and 512 edges; reconstruction allows at most 256 vertices and 1024 polygon points, with a shared 64 million predicate-work budget across edited bodies. These limits reject excessive work before expensive halfspace reconstruction. A source without resolvable face/edge construction ancestry is rejected. A move or replacement that removes an unselected supporting face is rejected rather than silently deleting it. Delete-and-heal succeeds only when the remaining planes still enclose a valid finite volume; deleting an ordinary box wall leaves it unbounded and is rejected, while removing a redundant corner/chamfer support can be valid.

Curved, concave, pocketed or multiply bounded stock; coplanar face subdivisions; surface-body editing; general surface replacement; face splitting/merging; automatic propagation; and healing that needs new nonplanar carriers remain unsupported. These are explicit geometry limits, not alternative mesh approximations. Interactive acceptance remains for the user; the source audit did not run tests, probes or UI exercises.
