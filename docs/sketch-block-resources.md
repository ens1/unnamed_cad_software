# Portable sketch blocks

Sketch Blocks contract 2 adds portable block-resource contract 1. A `.tcadblock` file contains exact application-owned point/member intent, internal relations, an insertion origin, a resource identity and exporting document/part/sketch/block provenance. It contains no kernel objects, viewport meshes, fonts, renderer objects or external file dependency.

In an active sketch, create a block from selected independent members, or select an existing block and choose **Export Sketch Block**. Export resolves external parameter expressions against the effective configuration into explicit millimeter/radian literals. Internal dimensions and geometric relations remain editable source intent. Export preserves source control seeds; it does not independently certify that a constraint system or resulting solid is valid. Imported source is evaluated through the ordinary sketch and geometry path.

Choose **Insert Block From File** under the Block group to import a resource into another sketch or document. Select a file, set the insertion anchor, then edit translation, rotation, positive uniform scale, construction state or suppression while viewing the model. The file creates a reusable local definition and its first instance with fresh output identities. **Accept** finishes the local block operation; **Apply Sketch** commits the shared validated sketch draft. **Cancel** restores the starting checkpoint. File selection is an operating-system dialog; block geometry and editing remain in the same model workspace.

Imported blocks are detached local snapshots. They rebuild without the original file and never follow external file changes automatically. Definition properties retain the resource identity, canonical content hash, exporting source hash and original-to-local control/member/relation identity correspondence. To adopt a replacement, edit the local block definition and choose **Update From Library**. The replacement must have the same resource identity. Compatible source identities retain existing local controls and instance output mappings; retiring referenced outputs requires explicit repair or Explode. Failed input leaves the earlier valid source available. Updating participates in the same pending sketch transaction and can be cancelled.

Exporting an imported definition retains its resource identity and portable source identities, including after component-library copying or Make Unique. Historical provenance remains unchanged during remapping; only the portable-to-local correspondence changes. A new exported snapshot records its actual exporting document/source and content. Newly authored controls receive their own identities. The format is a reuse mechanism with explicit updates, rather than a live cross-document equation dependency.

Admission is bounded to 16 MiB, 512 local controls, 128 relations, the existing 4096-member ceiling, and 16384 work units, calculated as `(controls + members) × (relations + 1)`. These bounds limit synchronous source editing and validation; evaluated model geometry still runs in the persistent worker. Coordinates and expressions must be finite, source IDs distinct and bounded, and portable expressions self-contained. Length/angle units are explicitly `mm`/`rad`. Unsupported version, unit, expression or source topology fails with a diagnostic.

Active block editors publish `sketch-block-field` values and `sketch-block` readers/setters for naming, origin/anchor coordinates, placement expressions and suppression. Stable editor identities prevent a control from a cancelled operation from editing its successor. Runtime file commands expose availability and disabled reasons. Persistent definitions/instances expose edit, insert, export and Explode actions where applicable; complete source remains under Advanced Source. Custom layouts can repeat or place these semantic controls, and CSS can style their roles/IDs independently of the default dock.

Nested blocks, a searchable/indexed library browser, live linked parameter equations, nonuniform scaling, scale solve variables and a full local drawing-tool suite remain work. This implementation was compiled, formatted and linted; no code tests or manual smoke tests were written or run. Interactive acceptance remains with the user.
