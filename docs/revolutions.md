# Native revolutions

Revolution intent version 1 adds omitted-default options to the readable existing `Revolve` operation: reverse, midplane, independent second angle, angular start offset, thin section and additional feature-output scope. Existing origin/axis and associative `AxisSource` definitions remain valid. Expressions use document angular/length units; the total extent is positive and at most one full revolution. Midplane and independent second direction are mutually exclusive.

All closed material regions, including compatible holes, come from current solved native sketch definitions. Thin sections use the same exact straight/circular offsets as extrusion, with one-side, two-side or midplane thickness and flat open-chain caps. Native member-to-edge constructor lineage identifies each region and its generated walls; relative region area is not an identity. A control-hull proof requires coplanar sections in one axis half-plane. Axis-crossing or uncertain self-overlapping sections are rejected.

The adapter sweeps the real curve carriers through eight angular construction intervals. These are exact revolution surfaces and circular connecting curves, not mesh sections. Every nonzero start angle rotates the carriers; a closed sweep requires the exact full-revolution extent rather than snapping a nearby angle. For a profile with a single connected boundary chain on the axis, the stationary chain is excluded from the swept skin and native poles are collapsed. A single moving curve is split at its actual parameter midpoint before construction. Partial-revolution caps reuse the actual skin edges and stationary axis chain. Holes touching the axis, isolated or interior moving-boundary pole contacts, multiple disconnected axis contacts, and an axis-bound span inside a rational curve require additional singularity reconstruction and fail explicitly. The adapter also rejects vertices between its axis tolerance and the native constructor's broader pole tolerance, avoiding an unrequested native collapse. Positive-weight per-span control bounds guard rational carriers, including interior knot contacts.

Wall references contain authored source-member closure, thin-side/piece identity and angular station. Cap references contain the complete region's member closure and start/end intent. Angular connecting edges use source endpoint/member ancestry, so a two-member closed contour does not collapse both connectors onto one face-pair identity. Other shared edges follow incident constructor faces; stationary cap edges are named from their original member closure. Positions, angles, relative areas, temporary kernel IDs and centroids do not name the result. Topology-changing edits can replace identities. Explicit Boolean intersection curves use known constructed surface-carrier ancestry; disconnected edges with the same carrier closure fail clearly until segmented ancestry is supported. Broader Boolean provenance/robustness limits remain recorded in the coverage inventory.

New/join/cut/intersect modes consume selected current body outputs. Duplicate native bodies are removed from scope. Join carries one shared tool through the scoped body set; intersect accumulates each material region against the original body set. Unsupported or invalid Boolean geometry prevents confirmation. Docked fields and semantic quantity/options elements participate in the persistent-worker draft, current-result validation, checkpoint Cancel and one undoable Apply path.

Source inspection and compilation are engineering evidence. No tests, probes or interactive acceptance were run for this implementation.
